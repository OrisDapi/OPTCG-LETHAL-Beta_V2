# ⚔️ OPTCG 斬殺計算機 (Lethal Calculator)

專為 **One Piece Card Game (航海王卡牌對戰)** 設計的終局斬殺與側防機率計算機。
支援 iOS (iPhone/iPad) 與 Android (安卓) 手機以 **PWA 原生 App 形式** 離線使用。

---

## 🌟 主要功能

- **我方場面配置**：
  - Leader 與 5 個角色欄位，攻擊力自由調整（0K ~ 13K）。
  - 可用 DON!! 卡數量自由設定（最多 10 張）。
- **對方場面配置**：
  - 對方 Leader 攻擊力調整（0K ~ 13K）。
  - 5 個角色欄位為 Blocker 開關（可抵擋一次攻擊）。
  - 生命卡數量設定（0 ~ 10 張）。
- **🃏 手牌側防（Counter）精確評估**：
  - 10 個手牌卡槽，每張卡牌可獨立點擊切換：`無側防` / `1K` / `2K`。
  - 即時統計總側防數與總防禦力（例如：`3張 (1×1K + 2×2K) = 5K`）。
  - 提供一鍵快捷鍵：`全部清空`、`全設 1K`、`全設 2K`。
- **📊 斬殺機率與動態規劃演算法**：
  - **DON!! 水位填充分配**：自動計算最抗側防的攻擊加成。
  - **最佳防禦評估**：精確模擬對手最優出牌防守邏輯，不浪費防禦值。
  - **圓形機率儀表**：即時顯示成功斬殺機率（%）。
  - **側防卡抗性網格**：顯示 0 ~ 10 張手牌情境下的可斬殺性與承受上限。
- **⚔️ 完整攻擊順序計劃**：
  - 明確規劃出擊順序：先騙 Blocker → 扣除生命卡 → 致命一擊。
  - 詳細標註被側防擋下的攻擊及消耗的卡片（如 `🃏 被側防 (1×2K)`）。
- **📱 跨平台 PWA 支援**：
  - 支援 iOS Safari「加入主畫面」與 Android Chrome「安裝應用程式」。
  - 離線 Service Worker 快取，出門打牌無網路也能使用。

---

## 📱 手機使用與安裝

1. 使用手機瀏覽器開啟本專案的 GitHub Pages 網址。
2. **iOS (iPhone/iPad)**：
   - 使用 **Safari** 開啟。
   - 點擊底部「分享」按鈕 ➡️ 選擇 **「加入主畫面」**。
3. **Android**：
   - 使用 **Chrome** 開啟。
   - 點擊右上角選單 ➡️ 選擇 **「安裝應用程式」** 或 **「新增至主畫面」**。
